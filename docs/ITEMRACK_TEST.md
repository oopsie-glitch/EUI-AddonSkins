# ItemRack refinement

Branch: `skin/itemrack-refinement`, based on main. Untagged; no CurseForge or Wago upload. Other addon experiments remain separate.

- Options panels expose the EUI shell instead of stacked grey gradients and opaque nested panels. Independent hover/queue panels retain a matching surface.
- Classic sliders use flat tracks, usable horizontal thumbs and thin vertical scroll strips. Native ranges, values and actions remain unchanged.
- Checkbox borders follow their inset boxes; helm/cloak tristate check colours remain native. Equipment selectors remain equipment controls, not checkboxes.
- Set selectors and queue movement buttons use flat navigation controls. Native control positions and tooltip/click handlers are preserved.
- Options, hover-menu and detached equipment icons use consistent square cropping and thin rarity-coloured edges. Empty slots retain Blizzard artwork with neutral edges. Existing missing-item warning borders, cooldowns, counts and checked states remain native. Set-editing selection uses ItemRack's native bright/faded icons; no corner markers are added.
- Detached quick-access buttons use a separate cosmetic-only path outside combat, restricted to exact ItemRack-owned button names. Lock/settings artwork references the installed EllesmereUI icons; queue and remove controls retain their native actions and tooltips. No secure attributes, native scripts, visibility, frame positions or state drivers are changed. General recursive scanning still skips protected frames.
- Queue/event/set row highlights use a subdued accent wash. Item-quality text colours and native highlight visibility are retained.
- Completed tab/menu changes style controls synchronously. Row updates repaint their list, individual highlight changes repaint their row; neither triggers a full options scan. No polling or global widget replacements are added.
- Options/log windows have no top accent bar. Tab underlines retain EUI's active-state behavior; tab labels use the global accent at full strength when active and a subdued tint when inactive. Lock/settings artwork and queue/close glyphs in the quick-access control menu follow that accent without changing equipment rarity colours. EUI tab label repaints retain the tint; theme updates use the existing refresh callback.
- Config rows use muted section headings without gradient banners, compact EUI checkboxes, consistent label sizes and aligned number fields with softer charcoal fills. Slider thumbs and endpoint labels are smaller; scrollbar arrows use the softer page-button treatment. Equipment controls are unchanged.
- Universal's compact direction selectors and their lazy popups use EUI dropdown/panel/button primitives. The original arrow hit targets and selection callbacks remain in place. Completed Config updates restyle the eleven pooled rows and their current controls, including number-field alignment after scroll reuse, without scanning the full options window.

Source shapes were checked against Rottenbeer/ItemRack and Bl4ut0/ItemRack-Universal. Universal detached buttons use `ItemRackButtonNItemRackIcon` (also exposed as `button.icon`/`button.Icon`); older `ItemRackButtonNIcon` names remain supported. Rarity colours use the global or modern `C_Item` API, then `ITEM_QUALITY_COLORS`; inventory IDs provide a quality fallback on clients without `GetInventoryItemQuality`. Completed custom-icon refreshes restyle only the owned equipment controls. No WoW client rendering or taint verification was performed.

`python3 scripts/package.py` checks all 16 suites, Lua syntax, catalogs/manifests and the 35-file one-folder archive with the MIT license. Regression fixtures cover native actions/returns, equipment versus checkbox treatment, gradients versus foreground art, slider geometry/ranges/reuse, dynamic menu items, local row callbacks, item colours/highlights, protected controls, combat deferral and disabled behavior. Detached-button fixtures additionally cover quality changes, neutral empty slots, native selection fading without corner markers, native secure actions/attributes, protected-parent hover menus, lock state, warm texture/hook reuse and zero full options scans during repeated equipment refreshes. Universal fixtures cover its icon names/fields, modern-only colour APIs, quality-table fallback, poor-quality versus empty slots, inventory-ID fallback, custom-icon refresh reuse and combat/disabled guards.

Versions and changelogs remain at main's release version until release preparation. Test ZIPs are identified by commit. Shared runtime helpers, saved variables and external addon sources are unchanged; reference sources and development files are not bundled.

Config fixtures cover heading repaint, native disabled-label colours, number editing/values, recycled-row anchors, checkbox/slider geometry, lazy picker actions, combat deferral and disabled skins. Fifty repeated Config updates create no additional slider regions, duplicate no hooks and perform no full options scans in the mocked environment. Font mocks preserve point sizes as EUI's public primitive does. In-game layout remains unverified.

The settings follow-up explicitly clears cached native decoration sources and supplies flat EUI panel fills for subframes, the icon grid and the unnamed saved-set list container. Dropdowns use a small neutral EUI arrow with reserved label space. Regular checkbox ticks are desaturated, accent-tinted and contained within their inset box; helm/cloak tristate textures remain native. Set-name inputs use the same charcoal fill as numeric fields; icon selection is a flat subtle wash and the current-set preview remains square. Legacy and modern gradient resets flatten native vertex gradients on reused highlights.

Regression fixtures include the actual unnamed saved-set container shape, retained set artwork/actions/hidden-set colours, native decoration repaint, dropdown arrow colour and label clearance, normal versus tristate checkbox semantics, lazy icon rows and highlight visibility, square preview/name editing, legacy/modern gradient APIs, repeated local refreshes and combat/disabled guards. These extend the existing mock checks; no in-game rendering or taint verification is claimed.

Accent fixtures cover omitted window bars, active/inactive tab labels, native tab actions/selection, EUI label repaint and hidden-label transparency, all four quick-access control tints, live colour changes, preserved rarity, hook reuse, combat deferral and disabled behavior.
