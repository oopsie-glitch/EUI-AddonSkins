# EUI AddonSkins 1.3.0 — PallyPower and skin improvements

- Added PallyPower styling for Blessing Assignments, options, menus and buff controls, with clearer columns and softer controls. The original lock button and native secure actions are preserved.
- Fixed Altoholic scrollbar styling, unused realm-row cells and category styling after changing tabs.
- Cleaned up BugSack's header, portrait, navigation and footer, without a top accent bar.
- EUI skin toggles now follow installed, enabled addons. Skins activate when their target loads; installation remains one addon folder and existing settings are retained.
- Reduced repeated refresh work in DBM, Details, Gargul and ThreatClassic2. PallyPower checkbox updates repaint only the affected control.
- Added `/euiskins diagnostics` for copyable loader status.

Requires EllesmereUI with Blizzard Skins+ enabled. Install supported addons separately. Extract `EUIAddonSkins` into `Interface/AddOns/` and restart the game. Enable individual skins through Blizzard Skins+ > Window Skins > Third-Party Addons.

Skins follow EllesmereUI theme and accent settings. Details meters, Tiny Threat and menus remain independently selectable from Details' settings pop-out or `/euidetails`.

PallyPower support targets the Forever beta layout. Protected controls retain native behavior; styling deferred during combat is applied afterward. Remove obsolete `EUIAddonSkins_*` folders if upgrading from the early multi-folder loader alpha.

Lua syntax, 16 automated mock regression suites and single-folder packaging checks pass. These checks do not establish in-game appearance, taint safety or FPS performance.
