# EUI AddonSkins 1.4.1 — Auctionator and Performance Improvements

- Themed Auctionator’s crafting and enchanting price controls, Search buttons and quantity-search popup.
- Reduced unnecessary skin refresh work for hidden addon windows.

Requires EllesmereUI. Supported addons are installed separately.

Install the release ZIP by copying its `EUIAddonSkins` folder into `Interface/AddOns/`.

All 18 automated regression suites, Lua syntax, manifests and packaging checks passed. Profession styling was confirmed in-game by the user; broader rendering, taint and performance were not measured in a WoW client.

Thanks to AngelosNaoumis for the hidden-root optimization in PR #2 and the Auctionator contribution in PR #1.
