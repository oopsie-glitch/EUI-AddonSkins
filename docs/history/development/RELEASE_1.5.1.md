# EUI AddonSkins 1.5.1 — RestedXP and Gargul Improvements

> Historical development snapshot. Versions, branch status and validation counts describe that snapshot; use [the engineering guide](../../ENGINEERING.md) and [release procedure](../../RELEASING.md) for current work.

RestedXP and Gargul skin updates with cleaner controls, improved readability and less unnecessary refresh work.

## RestedXP

- Refined guide headers and auxiliary windows, with centered guide titles and matching Active Targets/Items backgrounds.
- Updated options controls and fixed dark button labels after state changes and preview/page rebuilds.
- Added an accent-coloured navigation chevron with high-resolution artwork, a thin black outline and smoother rotation edges.
- Reduced repeated guide scans, options refreshes and font updates.

## Gargul

- Improved settings navigation performance with page-local refreshes.
- Refined the roll organizer, MS/OS/PASS window and accepted-roll notification.
- Fixed dropdown arrow click areas, overlapping controls, input alignment and slider grip sizes.

Requires EllesmereUI and its Blizzard Skins+ support. Install RestedXP and/or Gargul separately to use their skins; other supported skins remain included.

Download **EUIAddonSkins-1.5.1.zip** from Assets and extract its `EUIAddonSkins` folder into `Interface/AddOns/`, replacing the existing folder. Keep your SavedVariables to retain settings.

Automated regression and packaging checks passed. They do not establish every in-game client or addon combination.
