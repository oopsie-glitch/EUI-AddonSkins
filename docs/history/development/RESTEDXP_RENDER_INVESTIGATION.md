RestedXP native line references are from the supplied 4.11.32-era source. NaowhForever was inspected at `eab78a3`. Its [V2 replacement](https://github.com/naowh-gaming/NaowhForever/blob/eab78a3/Core/Integrations/RestedXP/Window.lua#L108-L135) suppresses native guide and active-step root alpha if enabled and renders `NaowhRXPWindow`. The trace records both roots and the replacement. NaowhForever being loaded is insufficient evidence that either integration ran.

AddonSkins resolves Forever through EUI's active profile, with a separate client/asset requirement for the bronze composition. It keys composition and panel state by frame identity and discovers existing V2 widgets on refresh. These are source facts. A hidden or replaced root, native higher-level fill, low effective alpha or an unexpected look/cache state are hypotheses for the current client. The trace records these separately. Matching rectangles and ordering are evidence of possible occlusion. A screenshot is still needed to judge final compositing, masks and texture contrast.

## Capture on WoW Forever

1. Replace only the installed `EUIAddonSkins` folder with the diagnostic ZIP's folder. Leave RestedXP, EllesmereUI and the active Forever look as usual. Reload, go out of combat and open a guide with a visible Current Step.
2. Run `/rxprender start naowh-on` (or use a label matching your current setup), take a screenshot, then run `/euiskins refresh`. After the UI settles, run `/rxprender snap post-refresh`.
3. Advance one step, scroll the list, switch guides, then close and reopen the guide. Use `/rxprender snap post-reopen` and take a second screenshot. If a visible change happens earlier, use `/rxprender snap changed` immediately.
4. Run `/rxprender stop` and `/reload` to flush the saved trace. Repeat with NaowhForever disabled, same EUI look and RestedXP mode, using `/rxprender start naowh-off`. If both RestedXP modes are available, repeat in the other mode and include the mode in the label. Use a fresh reload for each run so the trace attaches to the appropriate frames.
5. After the last stop and reload, open `WTF/Account/<account>/SavedVariables/EUIAddonSkins.lua` under the active WoW Forever installation. Send only the `rxpRenderDiagnostic` section or save that section as a text file. Include the labeled screenshots and tell us which Naowh RestedXP options were enabled. Each command session keeps up to 800 lines or three minutes, whichever comes first. Only the last four sessions are retained. `/rxprender clear` deletes the stored captures.

The probe starts only on command. It samples bounded known RestedXP surfaces, monitors selected object setters and refresh boundaries, and records short call stacks for observed writes. Protected objects are snapshot-only, and combat pauses capture work. Hooks become inert when stopped and are discarded by reload. This records Lua-visible state and sampled write paths. A missing write does not exclude a previously installed hook, engine-side visibility or a change before the capture started.

The normal PR package has zero probe code. To reproduce the diagnostic ZIP run `python3 scripts/diagnostics/build_rxp_render_probe.py /absolute/path/to/output.zip`. It injects the probe in a disposable copy and runs full packaging plus an opt-in/export smoke test. Replace the test build with the normal addon after the capture.
