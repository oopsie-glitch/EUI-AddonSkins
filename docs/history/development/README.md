# Development archive

Historical skin reports, audits and integration records. Their version numbers, branch state, test counts and old setup instructions apply to the recorded snapshot. Later sections can supersede earlier findings in the same report.

Use the [engineering guide](../../ENGINEERING.md), [benchmark guide](../../../benchmarks/README.md) and [release procedure](../../RELEASING.md) for current work. Keep these records for source versions, regression explanations and recovery; do not use them as pending-release checklists.

The original benchmark JSON results remain at `docs/benchmark-results.json` and `docs/acegui-callback-results.json`; the callback runner writes to the latter path.
