# EUI AddonSkins 1.5.0 — DBM Skin and Performance Improvements

> Historical development snapshot. Versions, branch status and validation counts describe that snapshot; use [the engineering guide](../../ENGINEERING.md) and [release procedure](../../RELEASING.md) for current work.

DBM skin update with separate Small and Big Bar styling, improved interface performance, and themed range/radar and info frames.

- Configure layouts, colours, borders, mechanic icons and background opacity through **Skin Options** beside the DBM window.
- Neutral headings follow the selected Blizzard Skins+ accent colour. Native warning colours, encounter data and movement locks remain intact.
- DBM continues to control timer size, position, scale and spacing.

Requires EllesmereUI and its Blizzard Skins+ skinning support. Install DBM separately to use this skin. Extract the attached ZIP into `Interface/AddOns/`, replacing the existing `EUIAddonSkins` folder.

Other supported skins remain included. Automated regression and packaging checks passed; they do not establish every in-game encounter or client combination.
