Slider thumbs and endpoint labels are smaller; scrollbar arrows use the softer page-button treatment. Equipment controls are unchanged.
- Universal's compact direction selectors and their lazy popups use EUI dropdown/panel/button primitives. The original arrow hit targets and selection callbacks remain in place. Completed Config updates restyle the eleven pooled rows and their current controls, including number-field alignment after scroll reuse, without scanning the full options window.

## Set-editing callback fix

Repeated input font/layout writes could dispatch `OnTextChanged` without a user edit. The set-name handler calls `ValidateSetButtons`, which disables/re-enables Save/Bind/Delete, hides/shows specialization controls and clears their ticks before loading saved state. Re-entering that handler during skin refresh can interrupt clicks and erase an unsaved specialization choice. The skin now compares the edit box's font against the public `GetFont` result, applies its input layout once and avoids repainting its internal text regions. Event/delay/script fields use the same guarded path without generic popup padding; their native geometry and callbacks stay intact.

The new simulated editing-flow regression fails against `89ddded` and passes with the fix. It covers new-set creation/saving, specialization selection across repeated refreshes, saved-set selection, bind/delete dispatch, unavailable actions, empty-set validation, internal text regions, numeric fields and multiline scripts. Warm refreshes perform no input font writes or set-name validation callbacks in this fixture.

A separate local check executed the upstream Universal `ValidateSetButtons`, `ToggleSpec`, `SaveSet`, `SelectSetList` and `DeleteSet` implementations with mocked frames and client services. It verified saved equipment and specialization/event assignments and successful selection/deletion. Third-party source was not added to the repository or package. This is simulated execution, not WoW verification.

The remaining module was reviewed for script/function replacement, mouse/keyboard access, native enabled/checked states, saved-variable writes, equipment attributes, geometry and menu callbacks. No additional direct action overrides or mouse-access changes were found. Existing tests cover config options, scrolling, queue/event row actions, menus, secure equipment, combat and disabled skins. Actual client hit-testing, input event delivery and taint remain unverified.
